# Worlds Apart product scope (21 October 2026)

Single core loop: **Choose worlds and sites → design outrageous space coaster → ride in first person or externally → revise → ride again.** All creative tools are free; transport, logistics, cargo, alloy, money, fleet and infrastructure tiers remain dormant and must not gate a ride.

The attached add-on pack (`Worlds_Apart_Next_Upgrade_Addon_v1_0.zip`) is the new user-supplied feature/QA specification, **not an executable patch**. In the latest context ZIP, the earlier Visual Round 08 was already integrated. Do **not** apply its old patch to this new base; it would conflict with live code.

### Next priorities

1. **Completed in Round 09:** tested geographic selectors, selected-site guideway endpoints, body-local markers and mobile 360 regression coverage.
2. **P1:** accurate globe texture and visible region of departure. Use appropriately licensed, pre-sized imagery and verify UV and lat/lon conventions. No building-level promises.
3. **P1:** robust adaptive near-planet rail connectors following axial rotation; coherent launch heading and safe surface arrival with terrain-aware altitude when available.
4. **P1:** freehand route drawing, banked spirals/loops, close flybys, track inspection and great visual ride choreography. No economy.
5. **P2:** Mars and other solid worlds, Saturn ring excursions (not gas giant landings), creator share/export, cinematic replay.

No new paid services, API keys, accounts, unnecessary trackers, or GPS access. Keep option for low-end Android graphics and offline procedural fallback.
